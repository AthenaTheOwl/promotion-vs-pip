# Playtest the audience intervention as a separate mechanism

Method update: October 18, 2026.

The printed deck's audience rule can change a player's incentives in the middle of a round. A bot simulation that omits that intervention measures a narrower game. Keep bot balance findings separate from evidence about what happens around a physical table.

The next proposed playtest uses two short sessions with the same deck and player count. In one, use the audience rule exactly as printed. In the other, omit it as an explicitly labeled experiment. Record game length, promotion and elimination outcomes, how often an audience intervention changes the active player's intended move, and the time a sidelined player waits before participating again.

Ask players to identify the decision that changed after an intervention. A funny moment and a useful strategic choice can coincide, but laughter alone does not establish balance. Preserve the existing cards, role-only names and printed rules until the playtest supplies a reason for a specific change. This refresh changes no flavor text, card effect or print layout.
